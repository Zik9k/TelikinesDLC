# Zik9k Client — Minecraft 1.21.11

Initial Fabric client project with an empty ClickGUI.

## Current state

- Fabric client mod
- Minecraft 1.21.11
- Java 21
- `Right Shift` opens the GUI
- GUI intentionally contains no modules yet

## Build

Use IntelliJ IDEA with the project imported as a Gradle project, then run the generated `runClient` configuration.

Or, with Gradle installed:

```bash
gradle build
```

The built JAR will appear under `build/libs/`.
