# TelikinesDLC

**Fabric-клиент для Minecraft 1.21.11**

Удобное меню · модули · визуалы · косметика · настройки под себя

---

## О проекте

**TelikinesDLC** (Zik9k Client) — клиентский мод на **Fabric 1.21.11** с собственным ClickGUI, визуалами и системой косметики в стиле меню из референсного видео.

Проект для себя и друзей.  
Не связан с Mojang / Microsoft.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для **1.21.11**
2. Положи [Fabric API](https://modrinth.com/mod/fabric-api) (под 1.21.11) в папку `mods`
3. Положи **TelikinesDLC / zik9k-client** `.jar` в `mods`
4. Запусти игру
5. Открой ClickGUI: **Right Shift**
6. Открой гардероб: **K**

## Косметика

Добавлено отдельное меню **«Гардероб»**:

- Шляпа
- Лицо
- Спина
- Крылья
- Эффект
- Эмоция
- Питомец
- поиск по предметам
- предпросмотр персонажа
- кнопка **«Снять всё»**
- состояние **НАДЕТО / НАДЕТЬ**
- заблокированные предметы
- счётчик валюты

Сейчас в системе есть оригинальные процедурные косметики по мотивам референса: **Корона**, **Красно-черные крылья**, **Синяя аура** и дополнительные тестовые предметы.

Косметика отображается и в мире у локального игрока. Меню открывается клавишей **K**.

## Сборка из исходников

**IntelliJ IDEA:** открой проект как Gradle → конфигурация `runClient`.

**Или в терминале:**

```bash
./gradlew build
```

На Windows:

```powershell
.\gradlew.bat build
```

Готовый jar: `build/libs/`

В репозитории также добавлен GitHub Actions workflow для автоматической сборки Fabric-мода на Java 21.
