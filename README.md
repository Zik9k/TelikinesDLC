# TelikinesDLC

**Fabric-клиент для Minecraft 1.21.11**

Удобное меню · модули · визуалы · настройки под себя

---

## О проекте

**TelikinesDLC** (Zik9k Client) — клиентский мод на **Fabric 1.21.11** с собственным ClickGUI и набором функций, которые будут дополняться в обновлениях.

Проект для себя и друзей.  
Не связан с Mojang / Microsoft.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для **1.21.11**
2. Положи [Fabric API](https://modrinth.com/mod/fabric-api) (под 1.21.11) в папку `mods`
3. Положи **TelikinesDLC / zik9k-client** `.jar` в `mods`
4. Запусти игру
5. Открой меню: **Right Shift**

## Сборка из исходников

**IntelliJ IDEA:** открой проект как Gradle → конфигурация `runClient`.

**Или в терминале:**

```bash
./gradlew build
```

На Windows:

```powershell
.\gradlew.bat build
```

Готовый jar: `build/libs/`
